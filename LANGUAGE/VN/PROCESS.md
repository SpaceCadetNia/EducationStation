# Vietnamese games — working process

How lessons, voices and the reader fit together, and how to add to them.
All paths below are relative to this `VN` folder.

## Layout

```text
data/lessons.js        lesson sets (sentences + English) used by every game
data/glossary.js       running glossary: meaning of every word used so far
GLOSSARY.md            readable glossary, generated by tools/glossary.py
reader/                Đọc Bài: read-along player (first game / capability test)
voice-samples/         short voice recordings used for cloning (private)
tools/make_voices.py   generates audio clips for every lesson and voice
Make Voices.command    double-click wrapper for make_voices.py (macOS)
audio/                 generated clips + manifest.js (read by the reader)
```

Games launch from the Language Garden menu one level up. Each game is a folder
here with its own `index.html`, uses the shared 1024×768 stage, and has a small
top-left back link to the Vietnamese menu (`../../index.html#vn`).

## 1. Add a lesson

Edit `data/lessons.js` and append an entry:

```js
{
  id: "bai-2",              // folder name for its audio; never rename once used
  title: "Bài 2",
  focus: "ng",              // letters to highlight in red (optional)
  sentences: [
    ["Vietnamese sentence", "English meaning."],
    ...
  ],
  align: [                  // one object per sentence, same order
    { "word": "matching English", "other": ["two", "parts"] },
    ...
  ]
}
```

- Type Vietnamese normally; the tools normalise accents (NFC).
- Leave out the final period; it is added when generating audio.
- `align` tells the reader which English to light up when a word is tapped or
  spoken. Copy the English text exactly; several Vietnamese words may point at
  the same English (e.g. both words of *ghê sợ* → "Afraid of").
- Then update the glossary (below).
- The reader currently shows the first lesson; a lesson picker comes when
  there are several.

### Glossary

Every word used in any lesson gets an entry in `data/glossary.js`
(`"word": { en: "meaning", note: "optional" }`, lowercase key), plus common
two-word phrases under `phrases`. After changing lessons, run:

```sh
python3 tools/glossary.py
```

It lists words that still need a meaning (exit code 1 if any), `align` entries
that don't match the English, words no lesson uses any more, and rebuilds `GLOSSARY.md`, grouped by the lesson that first
introduced each word. Avoid a bare `word:` inside meanings or notes; the simple
parser treats it as a key.

## 2. Record voice samples (only for a new cloned voice)

See `voice-samples/README.md`. In short: quiet room, phone voice memo,
5–8 seconds of natural reading, 2–3 takes. Clips longer than 8 s are trimmed.
Only use voices of adults who agreed to it. The file name becomes the voice id
(`Sample3.m4a` → `sample3`).

## 3. Generate audio

Uses VieNeu-TTS (open source, Apache 2.0), which runs offline on the Mac after
a one-time download of about 650 MB. It makes, for every voice:

- one clip per sentence: `audio/<voice>/<lesson>/s01.m4a` …
- one clip per unique word: `audio/<voice>/<lesson>/words/<word>.m4a`
- an updated `audio/manifest.js` listing what exists

Voices = every recording in `voice-samples/` (currently one: `Sample3`).
Built-in VieNeu voices can be added for comparison via `PRESETS` at the top of
`tools/make_voices.py` (off by default). Keep only the recording you want the
games to use; delete the others and their `audio/<voice>/` folder.

**Easiest:** double-click `Make Voices.command`. Output is also saved to
`audio/make_voices.log`.

**From Terminal**, in this folder:

```sh
export PATH="$HOME/.local/bin:$PATH"
PY="$(uv python find --python-preference only-managed 3.12)"
uv run --no-project --python "$PY" \
  --with vieneu --with "librosa==0.11.0" --with "numba<0.68" \
  python tools/make_voices.py
```

Shortcut: the `vt` script in this folder runs the same command, so
`./vt --only sample3` works in any Terminal window.

Options (add to the end):

| Option | Effect |
| --- | --- |
| `--only sample3` | one voice only |
| `--redo` | regenerate clips that already exist |
| `--sentence bai-1:6` | only that sentence (always regenerated); prints its phonemes |
| `--takes 3` | with `--sentence`: make 3 alternatives in `<lesson>/takes/` instead of replacing |
| `--fixes` | turn on our corrections (looser short-sentence cap, retries, end padding); off by default |
| `--check` | list clips that end mid-word (cut off), then stop |
| `--fix-cutoffs` | delete cut-off clips and regenerate them |
| `--temperature 0.4` | steadier, less varied delivery (model default 0.8) |
| `--say "text"` | with `--sentence`: speak this text instead (try respelling or punctuation) |

Existing clips are skipped, so after adding a lesson just run it again.
To redo a single bad clip, delete that one `.m4a` and run again.

### Setup gotchas (already handled in the scripts)

- **uv not found:** it installs to `~/.local/bin`; add that to `PATH`
  (install with `curl -LsSf https://astral.sh/uv/install.sh | sh` if missing).
- **llvmlite build fails:** uv picked an Intel (Homebrew) Python, or the newest
  numba has no prebuilt package. Use uv's own arm64 Python
  (`--python-preference only-managed`, check with `file -bL "$PY"` → arm64),
  don't run inside another virtualenv, and keep `numba<0.68`.
- **onnxruntime "External data path escapes model directory":** newer
  onnxruntime rejects the Hugging Face cache's symlinked weight files.
  `make_voices.py` detects this, moves the real files into place, and retries.
- The "unauthenticated requests to the HF Hub" warning is harmless.

## 4. Review in the reader

1. Start the EducationStation server and open Language Garden → Tiếng Việt →
   Đọc Bài (refresh if it was already open).
2. 🔈 shows the voice in use. If several recordings exist, **Giọng đọc · Reader**
   switches between them (remembered per device). The browser's computer voice
   is only offered when there are no recordings at all.
3. Play each sentence, then tap single words, especially tone pairs
   (ghé / ghế / ghẹ / ghẻ).
4. With a recorded voice, 0.8× on the speed slider is normal speed.
5. Tapping a word lights up its English match and shows its meaning (and any
   phrase it is part of) from the glossary. Hidden when English is off.
6. **▶ Từng chữ** reads the sentence word by word from the single-word clips,
   with exact highlighting. It always matches the word clips, so it is the
   fallback when a whole-sentence clip is wrong.

Anything without a clip falls back to the computer voice, so a missing file
never breaks the game.

## 5. Fixing pronunciation

The model can occasionally get a tone or word wrong. In order of effort:

0. If a sentence ends abruptly or repeats a word, it was probably cut off:
   run `./vt --check`. VieNeu limits short sentences (≤4 syllables) to about
   2.2 s, so a voice cloned from a slow recording runs past it. First choice:
   record the sample at a normal conversational pace (see voice-samples/README.md).
   If that is not enough, `./vt --fix-cutoffs --fixes` raises the limit, retries
   clips that end mid-word, and adds a short silence at the end.

1. Make alternatives and keep the best: `./vt --sentence bai-1:6 --takes 3`
   (add `--only <voice>` for one voice). Listen to `audio/<voice>/bai-1/takes/`,
   copy the best over `s06.m4a`, then run `./vt` once to refresh the manifest.
   Results vary run to run, so a retake often fixes it.
2. Check the printed phonemes. If a word is converted wrongly, try a different
   spoken text with `--say` (extra comma, lowercase, split phrase). When one works,
   store it as a third item on that sentence in `data/lessons.js`, e.g.
   `["Ghe ghé vô bờ", "The boat comes to the shore.", "Ghe ghé, vô bờ."]`.
   The game still shows the first item; only the audio uses the third.
3. If single words are right but the sentence is wrong, the model is slipping on
   context: try steadier takes, `./vt --sentence bai-1:8 --takes 3 --temperature 0.4`.
4. Try another voice for comparison (`--only <voice>`).
3. Record that word or sentence by hand and replace the clip: delete the old
   `.m4a` and save the recording with the same name as `.m4a` or `.wav`
   (`.m4a` wins if both exist). Rerun the tool so the manifest picks it up;
   it skips clips that already exist, so the recording is kept.

## 6. Privacy and publishing

The language section is published with EducationStation (not linked from the
public menu), including the lesson audio and the voice recording in
`voice-samples/`. Only generation logs and scratch files stay local; the sync
command in `../README.md` excludes them. Only use a voice whose owner is happy
for it and clips made from it to be online.
