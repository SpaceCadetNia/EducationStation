# VN — Vietnamese Homework Games

Vietnamese-language games and practice activities for Vietnamese homework.
They launch from the Language Garden page (`../index.html`).

See `PROCESS.md` for how lessons, voices and games are made.

## Publishing

Published with EducationStation, including the lesson audio and the voice
recording it was made from. Generation logs stay local (see `../README.md`).

Games here reuse the proven 1024×768 stage (`../../shared/stage.js`) and the
same navigation cues: a small top-left back link to `../index.html#vn`.
